Resposta:
Aqui está a função em Python que você pediu:

```python
def pares_maiores_que_10(numeros):
    pares = []
    for numero in numeros:
        if numero % 2 == 0 and numero > 10:
            pares.append(numero)
    return pares
```

A lógica utilizada na função é a seguinte:

1. A função `pares_maiores_que_10` recebe uma lista de números inteiros como argumento.

2. É criada uma lista vazia chamada `pares` que será usada para armazenar os números pares maiores que 10.

3. O código entra em um loop `for` que itera sobre cada número na lista de entrada.

4. Para cada número, é verificado se ele é par (`numero % 2 == 0`) e se ele é maior que 10 (`numero > 10`).

5. Se ambos os critérios forem atendidos, o número é adicionado à lista `pares`.

6. Após o loop terminar, a função retorna a lista `pares`.
