Resposta:
Aqui está uma função em Python que faz o que você pediu:

```python
def pares_maiores_que_10(lst):
    return [n for n in lst if n % 2 == 0 and n > 10]

lst = [2, 8, 10, 12, 15, 18, 21, 24]
print(pares_maiores_que_10(lst))
```

A lógica utilizada é a seguinte:

- A função `pares_maiores_que_10` recebe como parâmetro uma lista de números inteiros.
- A função usa uma compreensão de lista para gerar uma nova lista que contém apenas os números que são pares (`n % 2 == 0`) e maiores que 10 (`n > 10`).
- Os números que passam nas duas condições são adicionados à nova lista.
